# 02. 슈퍼 로봇 합체 월드 — 기획 검토와 보완 (PROPOSED)

> 상태: **PROPOSED** · 2026-10-31 · 대상: [01_REQUIREMENTS_ORIGINAL.md](01_REQUIREMENTS_ORIGINAL.md) v1.0
> 표기: **REQUEST**(현준이·보호자 요구) / **PROPOSED**(이 문서의 설계안) / **UNKNOWN**(현준이에게 확인 필요) / **FACT**(코드 근거). 모든 RB 항목은 REQUEST로 시작하고 검증은 NOT_RUN이다.
> 원문을 고치지 않는다. 원문과 이 문서가 다르면 원문이 우선이고, 이 문서는 해석과 보완만 한다.

## 1. 한 줄 요약

원문의 방향(마을 안에서 로봇을 만나고 → 카드 → 전투 → 합체 → 강화)은 기존 고정 결정 L-01(월드 안에서 직접 체험)·L-02(기존 기능 유지)·L-03(왼쪽 조이스틱/오른쪽 맥락 버튼)과 잘 맞는다. 다만 **카드 7회와 확률 강화가 두 갈래 성장으로 겹치고**, **100단 합체를 그대로 세면 지루한 반복이 되며**, **24종 목록 안에 등급·합체형이 섞여 있다.** 아래에서 보완한다.

## 2. 현준이에게 물어볼 것 (UNKNOWN)

음성 구술만으로 뜻을 확정하지 않는다(기존 원칙). 답이 오기 전에는 괄호 안 **임시안**으로 만든다.

| ID | 현준이에게 하는 말 | 무엇이 바뀌나 | 임시안 |
|---|---|---|---|
| RBQ-01 | "카드 7번은 싸울 때 쓴 것만 세? 그냥 눌러도 세?" | 횟수 세는 기준 | 전투에서 쓴 것만 센다. 그냥 연타로 7이 차지 않게 |
| RBQ-02 | "카드 쓰면 없어져? 계속 있어?" | 카드 소모 여부 | 없어지지 않고 계속 쓴다(원문 4절) |
| RBQ-03 | "로봇에 타? 내가 로봇이 돼? 로봇한테 '가!' 해?" | 조종 방식 | 자동차·비행기처럼 **탑승해서 직접 조종** (기존 탈것 구조와 가장 잘 맞음) |
| RBQ-04 | "2대가 합체하면 어떻게 붙어? 위아래? 팔이 돼?" | 합체 그림·연출 | 몸통 로봇에 다른 로봇이 팔·등·다리로 붙는다 |
| RBQ-05 | "악당 로봇 이기면 어떻게 돼?" | 승리 표현 | 불꽃이 튀고 부품이 떨어져 "수리하러 돌아간다!" 하고 후퇴 |
| RBQ-06 | "카드 7번 다 쓰면 새 로봇이 나와? 지금 로봇이 세져?" | 7회 해금과 재료 강화의 관계 | 7회 = 새 카드/능력 확정 해금, 재료 = 등급 강화(별개 경로) |
| RBQ-07 | "로봇이 마을에서 따라다녀? 집에도 와?" | 동행·저장 | 마지막에 탄 로봇이 따라다닌다. 집에는 아직 안 들어옴 |
| RBQ-08 | "아빠 로봇도 합체할 수 있어?" | 기존 아빠 로봇(HW-002)을 200종에 넣을지 | 1차에는 넣지 않는다. 기존 모습 유지 |
| RBQ-09 | "악당은 어디서 와? 무슨 이름이야?" | 악당 제국 이름·모습 | 가상의 "녹슨 톱니 제국" (임시 이름) |

## 3. 모순과 위험, 보완안

| # | 문제 | 보완안 (PROPOSED) |
|---|---|---|
| R1 | **성장이 두 갈래로 겹친다.** 카드 7회는 반드시 해금되는데, 재료 강화는 확률로 실패한다(원문 4·5절). 아이는 왜 어떤 건 되고 어떤 건 안 되는지 헷갈린다. | 7회 해금은 **항상 확정**. 강화에는 **보장 장치**: 실패하면 "희망 별" 1개를 받고, 별 2개면 다음 강화는 반드시 성공. **1차는 강화 100% 성공**으로 시작하고, 실패 연출은 2차에 넣는다. 슬롯머신식 연출·유료 재화는 금지(L-06). |
| R2 | **100단 합체가 반복 노가다가 된다.** 실제 로봇 100대를 모으게 하면 진행이 너무 길다. | 2·3단만 실제 로봇 대수, 4단 이상은 **"합체 레벨" 게이지**로 승리마다 오른다(5절 표). 원문 3절의 "부품과 능력을 순차 결합"과 같은 뜻이다. |
| R3 | **24종 목록 안에 종류가 섞여 있다.** 02~04 폴리스와 18·19는 성장 등급(황금·다이아) 이름과 겹치고, 21~24는 개별 로봇이 아니라 합체 형태다. "색만 바꾼 반복 금지"(6절)와 부딪힐 수 있다. | 24종을 **기본 로봇 20 + 합체 형태 4**로 나눠 관리한다. 02~04 폴리스는 ① 같은 경찰 로봇의 등급 그림으로 쓰거나 ② 외형을 완전히 다르게 그린다 — 현준이에게 고르게 한다(RBQ 후보). 이름은 현준이가 지은 그대로 보존한다. |
| R4 | **기존 작품과 겹칠 위험.** 원문이 실제 작품 두 개를 참고로 든다. "메탈 ○○"(01·06·12)는 한 작품 제목과 같은 낱말로 시작한다. | 원문 이름은 **작업명**으로 보존한다. 화면 표시명은 상표 검색 후 확정한다(검색: NOT_RUN). 외형·변신 연출은 참고 작품의 모양·색 배치를 따라 하지 않는다. 자동차→로봇 변신 연출은 기존 작품을 연상시키지 않는 방식(예: 부품이 날아와 붙기)으로 한다. |
| R5 | **"사람 얼굴 아님" 원칙과 기존 캐릭터.** 기존 아빠 로봇(`RobotArt.tsx`)과 로봇 친구는 얼굴형 머리가 있다(FACT). | 신규 로봇만 바이저·램프 눈으로 그린다. 기존 캐릭터는 L-02에 따라 그대로 둔다. 바꿀지는 RBQ-08에서 묻는다. |
| R6 | **전투 표현.** | 원문 7절 그대로: 기계적 무력화 → 후퇴 → 재도전. 탑승자 부상·피·폭발 사망 연출 없음. 내가 져도 잃는 것 없이 "수리하고 다시!" |
| R7 | **"다른 나라에서 온 악당".** 월드에 이미 실제 나라 이름 섬(일본·독도)이 있다(FACT: `src/game/kid-world.ts`). | 악당은 **가상의 로봇 제국**으로만 둔다. 황금 강철 지역은 실제 나라 섬과 떨어진 곳에 두고, 국기·실제 나라를 악당과 연결하지 않는다. |
| R8 | **200종 그림 예산.** | 손으로 그리는 것은 24종(2차)까지. 나머지는 부품 조합(몸·머리·팔·등 장비)으로 만들되, **실루엣 부품이 2개 이상 달라야 한다**는 규칙을 단위 테스트로 강제한다(3차). |
| R9 | **오른쪽 버튼이 너무 많아진다.** 카드·공격·특수·합체 + 기존 맥락 버튼. | 상황에 맞는 버튼만 보인다: 걸을 때는 `로봇 만나기/타기`, 탑승 중에는 `카드`·`공격`, 합체 가능할 때만 `합체`. 한 번에 최대 3개. |
| R10 | **저장 형식.** 저장에 로봇·카드가 새로 들어간다. | 기존 별코인·자동차·집 저장을 지킨다(L-05). 자세한 위험은 [03](03_ENGINEERING_PLAN.md) §3. |

## 4. 요구사항 ID와 수락 기준

### 1차 — 한 판에 이어지는 로봇 플레이 (vertical slice)

| ID | 요구 | 수락 기준 |
|---|---|---|
| RB-01 | 마을에 로봇이 돌아다닌다 | 서로 다른 로봇 3종 이상(경찰·소방·비행)이 마을을 걸어 다닌다. 사람 얼굴이 아니다. |
| RB-02 | 로봇을 만난다 | 가까이 가면 `로봇 만나기` 버튼. 누르면 그 로봇 카드를 얻고 연출이 나온다. |
| RB-03 | 로봇에 타서 조종한다 | `타기`를 누르면 조이스틱으로 로봇을 움직인다. `내리기`로 원래 현준이로 돌아온다. |
| RB-04 | 카드 사용 횟수 | 카드에 `n / 7`이 보인다. 전투에서 쓸 때만 +1. 새로고침해도 남는다. |
| RB-05 | 7회 해금 | 7이 되면 "축하해! 새로운 로봇 카드가 열렸어!"가 나오고 새 카드/능력이 열린다. 원래 카드는 남는다. 해금은 한 번만. |
| RB-06 | 기본 전투 | 마을 가장자리의 악당 로봇과 **월드 안에서** 싸운다(별도 화면 아님, L-01). 이기면 악당이 후퇴하고 재료를 준다. 져도 잃는 것 없이 후퇴·재도전. |
| RB-07 | 2단 합체 | 로봇 2대를 가지고 있으면 `합체` 버튼. 합체한 모습이 화면에 나오고 힘이 세진다. |
| RB-08 | 3단 합체 | 3대 합체. 2단과 다른 그림. |
| RB-09 | 경찰 로봇 | 경찰 로봇이 1차 로봇에 들어 있고 합체에 참여한다(원문 "특히 중요한 세 가지" 1). |
| RB-10 | 강화 | 재료로 일반→강화 업그레이드. 1차는 항상 성공. |
| RB-11 | 기존 게임 보존 | 기존 저장(별코인·자동차·집)이 그대로 남고, 기존 검증 스크립트가 계속 PASS. |

**1차 완료 정의:** 한 번의 플레이에서 RB-01~10이 메뉴 화면 없이 월드 안에서 이어지고, 휴대폰(390×844)·태블릿(1280×900) 헤드리스 스크린샷으로 확인된다. 실기기·현준이 직접 플레이는 별도 항목(NOT_RUN)으로 남긴다. 원문의 "단순 목록·버튼 메뉴만으로는 완료 아님"을 그대로 적용한다.

## 5. 합체 단계 진행표 (PROPOSED)

2·3단만 실제 로봇 대수다. 4단부터는 **합체 레벨 게이지**가 승리할 때마다 오른다. 져도 레벨은 그대로다.

| 구간 | 승리 1번에 | 필요한 승리 | 다음 구간 열쇠 | 화면 |
|---|---|---|---|---|
| 2·3단 | 실제로 2~3대 결합 | — | 로봇 만나기 | 붙는 연출 |
| 3 → 10단 | +1 | 7 | 5단에서 카드 1장 7/7 | 5단: 새 무기, 10단: 1.5배 크기 |
| 10 → 20단 | +2 | 5 | 황금 강철 지역 도착 | 황금 강철 |
| 20 → 50단 | +3 | 10 | 다이아 재료 1개 | 다이아몬드 |
| 50 → 100단 | +5 | 10 | 보스 1번 이기기 | 궁극 합체 |

100단까지 약 32승. 한 번 놀 때 2~3승이면 15번쯤 놀아서 도달한다. RBQ-06 답에 따라 다시 맞춘다.

로봇 한 대의 등급은 **일반 → 강화 → 강철 → 황금 → 다이아몬드 → 궁극** 순서다(원문 5절). 합체 레벨과 로봇 등급은 따로 오른다.

## 7. 안전 원칙 (기존 원칙 재확인)

- 실제 결제·확률형 유료 뽑기 없음(L-06). 강화 확률은 게임 안 재료로만, 보장 장치 포함.
- 전투는 기계 고장·후퇴로만 표현. 사람이 다치는 장면 없음.
- 악당은 가상의 제국. 실제 나라·국기와 연결하지 않음.
- 아이 이름은 공개 저장소에 이미 있다. 공개 범위는 보호자 결정 사항(UNKNOWN)으로 남긴다.
