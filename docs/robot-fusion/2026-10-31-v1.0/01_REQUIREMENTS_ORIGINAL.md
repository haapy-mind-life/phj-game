기존 박현준 마을을 없애는 게 아니라, 마을을 돌아다니다가 로봇 친구를 만나고, 카드를 사용하고, 로봇을 합체시켜 악당을 물리치는 새로운 모험을 추가한다. 특히 중요한 건 로봇 200종, 카드 7회 사용, 황금·다이아몬드 진화, 2단~100단 합체, 끝없는 모험이다.

## 1. 게임의 핵심 콘셉트

박현준 마을에 200종 이상의 로봇이 등장한다. 플레이어는 마을을 자유롭게 탐험하면서 로봇을 만나고, 카드를 사용해 새로운 능력을 해금하며, 로봇을 합체시켜 더욱 강한 로봇을 만든다. 멀리 탐험하면 황금 강철 지역이 등장하고 강력한 악당 로봇을 만나게 된다. 게임에는 고정된 결말이 없으며 계속 새로운 모험을 즐길 수 있다.

## 2. 로봇 시스템

| 구분 | 요구사항 |
|---|---|
| 로봇 수 | 기본 목표 200종 |
| 로봇 외형 | 멋진 기계형 로봇 |
| 얼굴 | 사람 얼굴처럼 만들지 않음 |
| 등장 방식 | 마을 곳곳을 자유롭게 돌아다님 |
| 로봇 종류 | 경찰, 소방, 자동차, 비행, 바다, 공룡, 강철 등 |
| 성장 | 약한 로봇에서 강력한 로봇으로 진화 |
| 카드 | 카드를 장착하여 능력 사용 |
| 합체 | 2단, 3단부터 최대 100단 |
| 최종 형태 | 초강력 황금·다이아몬드 합체 로봇 |

메탈 카드봇과 또봇의 변신·합체 재미를 참고하지만 캐릭터 디자인, 이름, 설정은 독창적으로 제작한다.

## 3. 합체 시스템

| 합체 단계 | 특징 |
|---|---|
| 2단 합체 | 로봇 2대가 합체 |
| 3단 합체 | 로봇 3대가 합체 |
| 5단 합체 | 새로운 무기와 스킬 해금 |
| 10단 합체 | 초대형 로봇 등장 |
| 20단 합체 | 황금 강철 능력 획득 |
| 50단 합체 | 다이아몬드 로봇 진화 |
| 100단 합체 | 궁극의 초강력 합체 |

100단 합체는 단순히 로봇 100대를 화면에 쌓는 방식이 아니라, 여러 로봇의 능력과 부품을 순차적으로 결합하는 시스템으로 구현한다. 200종의 로봇을 수집하면서 다양한 합체 조합을 발견할 수 있다.

## 4. 카드 7회 사용 시스템

현준이가 특별히 설명한 핵심 기능이다. 처음에는 약한 로봇 카드를 사용한다. 카드를 7회 사용하면 다음 단계의 로봇이나 능력을 해금한다.

게임 화면 예시:

- 카드 이름: 메탈 경찰봇
- 사용 횟수: 3 / 7
- 안내: "카드를 7번 사용하면 더 강한 로봇을 사용할 수 있어!"
- 7회 사용 완료! "축하해! 새로운 로봇 카드가 열렸어!"

카드는 사라지지 않으며, 사용 횟수와 성장 상태를 저장한다.

## 5. 로봇 성장 시스템

기본 성장 방향: 일반 로봇 → 강화 로봇 → 강철 로봇 → 황금 로봇 → 다이아몬드 로봇 → 궁극 로봇

강력한 악당을 물리치면 더 좋은 강화 재료를 획득할 가능성이 높아진다. 업그레이드가 항상 성공하는 것은 아니지만, 실패하더라도 기존 로봇과 획득 재료를 잃지 않도록 설계한다.

## 7. 황금 강철 지역과 악당

기존 박현준 마을에서 멀리 이동하면 새로운 황금 강철 지역에 도착한다. 황금 강철 지역에는 특별한 재료와 강력한 로봇이 등장한다. 다른 나라에서 찾아온 악당이라는 설정은 가상의 로봇 제국으로 구성한다. 악당 로봇을 물리치면 카드와 강화 재료를 획득한다. 강한 악당일수록 높은 등급의 보상을 제공한다. 어린이 게임이므로 전투는 로봇의 기계적 무력화, 후퇴, 재도전 방식으로 표현한다.

## 8. 게임 모드

| 모드 | 플레이 방식 |
|---|---|
| 자유 탐험 | 마을과 새로운 지역 탐험 |
| 로봇 수집 | 200종 로봇 수집 |
| 카드 모드 | 카드 장착·사용·해금 |
| 로봇 합체 | 다양한 단계의 합체 |
| 로봇 전투 | 악당 로봇과 대결 |
| 보스 모드 | 강력한 악당에게 도전 |
| 황금 강철 모험 | 특별 지역에서 희귀 재료 획득 |
| 무한 모험 | 반복해서 새로운 적과 도전 등장 |

기존 집 꾸미기, 상점, 식당, 바다, 자동차, 박현준 러너 등은 유지한다. 로봇은 전투 모드에서만 등장하는 것이 아니라 일반 마을에서도 만날 수 있어야 한다.

## 9. 모바일 조작

- 화면 왼쪽에는 이동용 조이스틱을 배치한다.
- 오른쪽에는 카드, 공격, 특수 기술, 합체 버튼을 배치한다.
- 로봇 가까이 이동하면 상호작용 버튼이 나타난다.
- 모든 주요 기능은 손가락 터치로 사용할 수 있어야 한다.
- 키보드 입력창이 불필요하게 나타나지 않도록 한다.

## 10. 구현 우선순위

- **1차 — 실제 플레이 가능한 로봇 시스템:** 로봇 등장, 마을 이동, 카드 7회 사용, 기본 전투, 2단·3단 합체 구현.
- **2차 — 성장과 새로운 모험:** 로봇 종류 확대, 황금·다이아몬드 진화, 경찰 로봇, 황금 강철 지역, 보스 전투 구현.
- **3차 — 대규모 합체 월드:** 200종 로봇 수집, 최대 100단 합체, 다양한 게임 모드, 끝없는 탐험 시스템 구현.

## 핵심 완료 조건

게임에서 직접 로봇을 만나고, 카드를 사용하고, 로봇을 성장시키고, 합체한 로봇으로 악당을 물리칠 수 있어야 한다. 단순한 로봇 목록이나 버튼 메뉴만 추가하는 것은 구현 완료로 인정하지 않는다.

가장 중요한 목표: 현준이가 직접 움직이고, 직접 합체하고, 직접 로봇을 조종하는 재미있는 박현준 게임.

## 개발할 때 특히 중요한 세 가지

1. 경찰차가 아니라 **경찰 로봇**이다. 현준이가 직접 강조했다. 경찰 로봇 자체가 강력하고 다른 로봇과 합체할 수 있어야 한다.
2. **200종과 100단 합체는 서로 다른 개념**이다. 200종은 수집할 수 있는 로봇의 규모이고, 100단은 궁극의 합체 성장 단계다.
3. **기존 박현준 게임을 유지하면서 확장**한다. 로봇 게임으로 완전히 교체하는 게 아니라 마을 안에서 로봇 친구를 만나고 새로운 지역으로 모험을 떠나는 구조가 맞다.

다음 개발 작업에서는 로봇 그림이나 메뉴만 만드는 것이 아니라 **마을에서 움직이는 로봇 → 카드 사용 → 전투 → 합체 → 강화**까지 연결된 플레이 기능을 먼저 완성한다.
