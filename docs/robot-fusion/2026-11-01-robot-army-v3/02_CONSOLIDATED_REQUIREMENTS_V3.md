# 02. 로봇 소환 시계 + 100대 군단 통합 요구사항 v3.0

**정본 우선순위:** 현준이 최신 구술(2026-11-01) → v2 시계 요구 → v1 오픈월드 확장 요구.  
**출처:** 현준이/보호자 발언. 코드 구현 상태는 별도 `05_LIVE_GITHUB_HANDOFF.md` 참조.  
**요구사항 코드:** `RW`(기존), `RA`(이번 신규).

## 1. 게임의 중심 경험

현준이가 이미 알고 있는 박현준 게임의 큰 마을에서 뛰어다니고, 상점·집·바다·친구를 즐기는 중 **손목 로봇 소환 시계**를 열어 로봇을 불러낸다. 로봇과 함께 악당을 막고, 친구를 구하고, 도둑을 쫓고, 동료 로봇을 합체시킨다. 월드에 존재하는 로봇들은 100대 규모의 군단을 이루고, 6종의 전설 로봇을 만난다. 나중에는 군단 100대가 집결해 **한 몸의 거대 합체 로봇**이 되며, 거대 악당·작은 악당과 직접 맞붙는다.

**최우선 규칙:** 메뉴만 만들거나 숫자와 문구만 바꾸는 것은 구현으로 인정하지 않는다. 월드 좌표·엔티티 상태·이동·합체·공격·판정·보상 등 인과 관계가 동작해야 한다.

## 3. 새 군단 시스템 (v3)

### 3.1 로봇 개체 100대

- 월드에 **서로 다른 개체 ID**를 가진 100대의 로봇이 존재한다. 등록부 100개로만 끝내지 않고 월드 위치·상태·지역·행동을 가진다.
- **모두를 한 화면에 상시 렌더링할 필요는 없다.** 멀리 있는 개체는 결정적 위치/진행 상태로 유지, 가까이 오면 다시 나타난다.
- 군단 행동: 순찰, 팀 이동, 집결/대형 전환, 해산. 최소 2종 행동이 눈으로 확인되어야 한다.
- 기존의 30마을 속 생활과 공존. 아이가 걸어 다니면서 로봇과 마주친다. 도시·해변·외곽 등 다양한 지역으로 배치한다.
- 현재 6종 카탈로그를 100개의 고유 개체로 복제할 수 있으나, 한눈에 모두 똑같아 보이지 않도록 실루엣·장식·색·무기·역할의 의미 있는 조합 다양성을 확보한다. 200종 독립 도감은 별도 장기 목표.

### 3.2 전설 로봇 정확히 6종

- `legendary = true` 또는 등급/분류 카테고리로 **6종 정확히** 정의한다. 100대 개체 중 몇 대가 전설로 나타나는지는 임시안(현재는 6대, 포함)으로 관리한다.
- 시계 도감에서 전설 별도 필터/섹션. 뚜렷하게 다른 실루엣·크기·전용 무기·기술·합체 기여.
- 전설 로봇이 100대 집결에 참여할 때 일반 로봇과 다른 부품/이펙트를 보이도록 한다.
- 이름·전설 기원·해금 규칙은 사용자 승인 전까지 PROPOSED. 로봇 자체의 수를 늘리는 것과 전설 **종 수 6개 고정**은 동시에 지킨다.

### 3.3 100대 집결 → 한 몸 초대형 합체

- 명확한 집결 대상, 100개 참여자 ID, 모이는 진행 과정, 완성 전과 후의 **구조적 변화**가 있다.
- `ready → gathering → assembling → giant-ready → fighting → split/return`와 같은 상태 전이를 실제 엔진에서 검증한다(상태명은 제안).
- 집결 중 100대 개체를 매 프레임 전부 개별 리액트 렌더링할 필요는 없음. **논리 개체 100대**를 유지하며 화면에 보이는 규모는 성능에 맞춰 대형/반짝 파츠/카메라 연출로 처리.
- **100/100이 되기 전에는 '100대 합체 완료' 표시 금지.** 같은 ID 중복 참가 금지, 참여자가 빠지면 완료하지 않음.
- 초대형 합체체는 2·3단 합체와 확연히 다른 하나의 거대한 몸/실루엣·거대 무기·공격 범위·전투 패턴을 가진다.
- 기존 '100단' 성장 단계와는 다른 시스템. 두 진행을 같은 상태 수치 하나로 합치지 않는다.

### 3.4 전투 — 거대 보스와 작은 적 모두

- 대형 보스: 고유 위치·반응·체력/실드·패턴(접근, 거리 두기, 공격 전조, 반격, 수리 후 복귀). 보스를 만나러 월드에서 이동해야 함.
- 소형 적: 거대 합체체가 압도적으로 강해 짧은 타격 후 무력화할 수 있음. 그러나 **플레이어가 직접 무기 조작·사거리/명중을 확인**해야 승리.
- 합체 중 전투 시작 금지 또는 명확한 시작 조건. 실패해도 로봇·전설·카드/재료는 잃지 않는다.
- 보스는 가상 로봇 제국 출신. 실제 국가/국민/국기와 연결하지 않는다.

## 4. 장기 성장과 수집 범위

- 로봇 등급: 일반 → 강화 → 강철 → 황금 → 다이아몬드 → 궁극.
- 기존 2/3단 합체를 유지하고 5/10/20/50/100단 성장형 합체도 별도 진행. 단계별 새 기능·외형 필요.
- 장기 도감 목표 200종 유지. 현재 100대 군단은 종수와 구별한다.
- 황금 강철 지역/보스/무한 탐험은 기존 세계와 이어져야 하며 별도 로봇 게임 탭으로 단절시키지 않는다.

## 5. 조작 UX

1. 탐험 HUD: 왼쪽 이동, 오른쪽 시계/기술/합체/상호작용. 버튼 겹침 금지.
2. 시계 탭: **소환**, **합체**, **임무**, 새로 추가되는 **군단**, **전설**로 확장하되, 7세 아이가 한두 번의 터치로 핵심 행동에 접근하도록 정보구조를 검토한다.
3. 화면이 작다면 탭/목록은 시계 안에서 스크롤하지만 탐험·전투 화면에 100개의 아이콘을 늘어놓지 않는다.
4. 군단 집결 시 멀리 있는 로봇도 **참여 중인 실제 데이터**가 바뀌는 것을 숫자, 화면 연출, 미니맵/간단 가이드로 이해할 수 있도록 한다.
5. 플레이어가 목표에 다가가야 행동 가능. UI 버튼으로 원거리 즉시 승리 불가.

## 6. 설계 충돌 사항과 결정 장부

| 문제 | 현재 판정 |
|---|---|
| 기존 6종 로봇을 '전설 6종'이라 부를 것인가 | **NO**. 신규 전설 6종이 필요 |
| 100대가 100종을 뜻하는가 | **NO 단정 금지**. 현재는 100개의 월드 개체로 해석(REQUEST + PROPOSED) |
| 100대 군단 = 이전 100단 성장인가 | **NO**, 별개 필드/메커닉 |
| 100대 합체 거대 로봇은 아군인가 적인가 | **UNKNOWN**. 사용자 의도 불명확. 기본 구현에서는 아군 합체 + 별도 거대 보스, 추후 방향 전환 가능하게 모델링 |
| 100대 안에 전설 6종이 포함되는가 | **PROPOSED: 포함**. 사용자 확정 전까지 편집 가능한 상수/콘텐츠 |
| 로봇마다 항상 화면에 보여야 하는가 | **NO**. 100개의 실제 상태는 유지, 근처만 렌더링해 성능 보존 |
| 이전 200종 도감은 제거되는가 | **NO**. 명시적으로 철회되지 않음. 장기 목표로 유지 |

## 7. 완료 수준의 명확한 구분

- **DATA_ONLY:** 100개 정의/도감 숫자만 추가 → 불합격.
- **VISUAL_ONLY:** 100개 로봇 이미지만 배치/합체 효과만 나옴 → 불합격.
- **INTERACTIVE_PARTIAL:** 군단 NPC가 움직임/전설 6종 플레이 가능하지만 100대 집결·보스가 없음 → 중간 마일스톤으로만 인정.
- **COMPLETE:** 고유 개체 100대, 전설 6종, 100개 참여 집결 후 한 몸 초대형 합체, 실제 거대/소형 전투, 모바일/기존 세계/저장 회귀 통과. 실기기는 UAT 별도.
