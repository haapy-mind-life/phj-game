## 2. 자동 테스트 명령(현재 저장소 확인 후 조정)

```bash
bun install --frozen-lockfile
npm test
npx tsc --noEmit
npm run lint
npm run build
npm run build:pages
```

기존 프로젝트에 설치/브라우저 실행 옵션이 준비된 경우:

```bash
node scripts/verify-robot-world.cjs
node scripts/verify-child-play.cjs
node scripts/verify-living-world.cjs
node scripts/verify-building-interiors.cjs
# 구현 후
node scripts/verify-robot-army.cjs
```

**주의:** 브라우저 스크립트는 미리보기 서버·Chromium/Playwright 환경변수가 필요할 수 있다. 로컬 문서/기존 `scripts/verify-robot-world.cjs`의 설정을 먼저 읽고 적절한 미리보기 주소에서 실행한다. 실패 시 환경 요인과 코드 오류를 구분해 보고한다.

## 3. 필수 시뮬레이션·속성 테스트

- `robotArmy.length === 100` / `unique IDs === 100` / 좌표 유효 / 중복 group index 무효.
- `legendarySpecies.length === 6` / 전설 이름·실루엣 키·능력의 최소 차별화.
- 도착 99개→미완료, 100개→정확히 한 번 완료, 동일 ID 100번→불가.
- 100대 군단/기존 작은 2·3대 합체/100단 성장 진행도가 서로 섞이지 않는다.
- 거대 보스 체력 0 도달 및 다른 보스/다른 시도와 보상 id 분리.
- 7회 강화, 기존 로봇 일반→강화→강철, 다른 종류 카드에 간섭 없음.
- 기존 저장 `version: 3`, 과거 차량과 업그레이드/집/별코인을 보존하는 save round-trip.
- 백그라운드/새로고침/지도 이동 중 월드 AI·타이머 중복/유실/엄청난 누적 이동 없음.

## 5. 검증 보고 출력 형식

각 테스트마다 `PASS|FAIL|PARTIAL|NOT_RUN`, 커밋 SHA, 실행 명령, 입력 방법(마우스/터치/키보드), 확인한 실제 상태, 스크린샷 경로, 재현 방법을 남긴다. 실기기 UAT는 아직 수행하지 않았다면 반드시 NOT_RUN으로 표기.
