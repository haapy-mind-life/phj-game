# 01. 신규 추가 요구사항 v3 — 로봇 군단·전설·거대 합체

**상태:** REQUEST (현준이의 2026-11-01 구술), PROPOSED (구현 해석), UNKNOWN (불명확).  
**변경 기준:** 기존 2026-10-31 v1, 2026-11-01 로봇 소환 시계 v2 위에 누적. 이전 요구사항 원문은 절대 삭제하지 않는다.

## 1. 현준이 발언의 핵심(의미 정리)

- “지금 로봇이 부족해. 로봇이 많아야 돼. 로봇 군사처럼.” → 게임 세계에 소수 로봇만 있는 것은 불합격. **많은 로봇이 군단처럼 활동**.
- “전설의 로봇들도 딱 6명만” → **전설 로봇은 정확히 6종**.
- “지도 있는 그 말[마을?]보다 더 많아야 돼. 100개 100개여야 돼.” → 최소 해석은 **월드의 로봇 개체 100대**. '마을'이라는 말은 음성 해석의 불확실성으로 별도 표시.
- “100개 로봇 중에서 다 함께 하면 … 엄청 큰 로봇 … 그 엄청 큰 로봇이랑 싸우는 거야.” → **100대가 관여하는 거대 합체와 거대 로봇 전투**가 필요. 거대 합체 로봇의 진영/소유 주체는 UNKNOWN.
- “작은 로봇이랑 싸우면 당연히 이기지만. 그래도 그렇게 만들어줘.” → **초대형 vs 소형 전투도 직접 가능**. 힘 차이는 자연스럽지만 화면 클릭만으로 승리 처리하는 것은 불가.

원문 인용은 사용자 제공 대화 일부이며, 의미 해석이 모호한 부분은 별도로 구분한다.

## 2. 신규 요구사항 등록부

| ID | 우선 | 요구(REQUEST) | 실제 수락 기준(요약) |
|---|---|---|---|
| RA-100 | P0 | 로봇 군단 100대 | 월드 상태에 고유 ID가 있는 **서로 다른 로봇 개체 100대**. 메뉴에서 100이라는 숫자만 적는 것으로 불합격. 기존 마을/거리에도 등장 |
| RA-101 | P0 | 군단처럼 활동 | 모이기·대형 유지·순찰·이동·흩어지기 중 최소 2개가 **시간과 월드 좌표에 따라 실제 변화**. 로봇은 임무 밖에도 존재 |
| RA-102 | P0 | 전설 로봇 정확히 6종 | 별도 타입/카탈로그에서 정확히 6개의 전설 로봇 정의, 고유 실루엣·기술, 시계 도감/월드 표현 |

| RA-106 | P1 | 거대 로봇과 전투 | 거대 상대 NPC와 충돌·사거리·HP/실드·행동·타격·승패·후퇴를 갖춘 월드 전투. 전투 현장 이동 필요 |
| RA-107 | P1 | 작은 로봇과의 전투 | 초대형 로봇이 작은 상대를 압도하는 힘 차이는 보여주되, 실제 공격/명중/승리 연출을 제공 |
| RA-108 | P0 | 기존 게임 유지 | 집/식당/바다/푸드트럭/러너/자동차/가족방/로봇 시계/7회 강화/2·3단 합체/구조·도둑 임무 유지 |
| RA-109 | P0 | 모바일에서 동작 | 로봇 100대 데이터가 있어도 손가락 조작과 렌더링이 심각하게 끊기지 않음. 화면 인근 렌더링만 활성화 가능 |
| RA-110 | P1 | 자유 전투·반복 플레이 | 100대 군단/초대형 합체/보스/소형 상대를 반복 즐기며 패배 시 소환 카드·성장치를 잃지 않음 |

P0/P1은 **실행을 위한 우선순위 제안**이다. 사용자가 최종 범위를 바꿀 수 있다.

## 3. 절대 혼동하지 말아야 할 사항

1. **로봇 100대(인스턴스) ≠ 로봇 100종(종류)**. 이전 요청 200종 도감은 여전히 장기 목표다. 초기 100대는 여러 종류의 로봇이 각각 별도 개체로 출현할 수 있다. 다만 외형을 모두 똑같이 복제한 군중은 재미 요구에 맞지 않아 비주얼 다양성 기준을 둔다.
2. **전설 6종 ≠ 기존 6종의 기본 로봇**. 현재 코드의 경찰/소방/하늘 및 7회 해금 로봇 3종을 재분류해서 숫자만 맞추지 않는다.
3. **100대 실제 집결 ≠ 기존 100단 성장 게이지**. 100대 고유 개체의 참여 여부가 실제 게임 상태로 검증되어야 한다.
4. **로봇 군단 ≠ 100개 DOM/SVG를 늘 화면에 그리기**. 멀리 있는 로봇은 상태를 유지하되 렌더링/애니메이션은 근처에서만 한다.
5. **거대 보스 전투 ≠ 전투 버튼 한 번 누르고 축하 문구**. 실제 움직이는 상대와 충돌/타격/체력 변화가 필요하다.

## 4. 원음성만으로 확정하면 안 되는 것 (UNKNOWN)

| ID | 질문/해석 갈림길 | 개발 중 임시 기본안 (PROPOSED, 사용자 발언으로 단정 금지) |
|---|---|---|
| RAQ-01 | 100대가 **아군**으로 합쳐 거대 로봇을 만들어 다른 거대 보스와 싸우나? 아니면 **적 로봇 100대**가 합쳐 거대 보스가 되고 플레이어가 싸우나? | 기본 플레이: 아군 100대가 모여 초대형 합체체가 되고 **별도 초대형 악당**과 싸우게 한다. 이벤트 모델은 양쪽 시나리오로 확장 가능하게 설계. 최종 확정 전 원문 삭제 금지 |
| RAQ-02 | 로봇 100대는 월드 전체 합계인가, 한 마을 합계인가? | **월드 전체 합계 100대**로 시작. 게임 속 30마을보다 많다는 비교를 채택하되 마을당 100이라고 해석하지 않음 |
| RAQ-03 | 전설 6종이 100대 군단에 포함되는가? | **포함**을 임시안으로 정해 총 활성 개체 100대 안에 전설 등장 6종을 반영. 추후 변경 가능 |
| RAQ-04 | 소형 로봇은 아군·연습상대·악당 중 누구인가? | 낮은 난도 악당 로봇을 우선 배치, 구조/동료 로봇에게 피해를 주지 않도록 함 |
| RAQ-05 | 100대가 언제 합체하는가? | 월드의 합체 장소/시나리오에서 직접 소환·집결 진행. 단일 버튼으로 즉시 100/100 채워지는 연출은 불합격 |
| RAQ-06 | 전설 6종의 이름과 특별한 능력은 무엇인가? | 임시 작업명·역할 제안 가능, **현준이가 이름을 정하기 전 확정 표기 금지** |

질문이 미결정이더라도 구현이 불가능해지는 것은 아니다. 위 임시안을 문서와 코드에 명시하고, 방향이 바뀌어도 대규모 재작성 없이 수정 가능한 데이터 설계를 우선한다.

## 5. 새 요구와 종전 요구의 우선순위

1. 2026-11-01 최신 구술(이 문서) > 동시대 이전 v2 > 2026-10-31 v1의 **충돌하는 제안 부분**.
2. 시계 디지털 카드/7회 강화/합체 한 몸/월드 전투·구조/터치 조작은 여전히 유지.
3. v1에서 언급된 '4단 이상은 게이지만 올리는 방식'은 **100대 실제 집결 요구를 대체하지 않는다**. 발전 단계와 군단 규모를 독립 필드로 둔다.
4. 기존 200종 수집 규모는 철회된 사실이 없으므로 보존. 숫자 100/200을 한쪽으로 일괄 수정하지 않는다.

## 6. 아동 친화 원칙

- “로봇 군사처럼”은 **로봇 팀/군단의 움직임과 장관**을 뜻한다. 실제 국가/정치/군대 선전 요소 없이 창작 메카 세계로 묘사한다.
- 소형·거대 대결은 기계 수리/후퇴/안전한 제압으로 종료. 피·상해·잔혹한 사망 연출 없음.
- 유료 강화·확률 뽑기·현금결제 없음. 패배로 카드/로봇/전설을 잃지 않는다.
- 로봇들은 기계형 바이저/장치형 디자인, 실존 메카 IP 캐릭터·변형 연출 복제 금지.
