# 박현준 게임 — 로봇 소환 시계·실제 합체·도움 임무 요구사항 v2.0

**요구 출처:** 현준이 구술 2026-10-31, 2026-11-01 및 기존 게임 관련 결정. **상태:** REQUEST / 일부 PROPOSED. 기존 `docs/robot-fusion/2026-10-31-v1.0/` 원문은 보존한다. 정정이 충돌하면 **11월 1일 발언이 우선**한다.

## 0. 핵심 재정의 — 가장 중요한 요구

> "카드를 따로 꽂는 게 아니라 시계에 저장돼 있어. 시계에서 카드 그림을 고르고 로봇을 부르면 나와. 약한 로봇을 7번 쓰면 업그레이드돼. 합체 버튼이 있어야 하고 실제로 합체돼야 해. 무기를 꺼내 싸우고, 친구가 위험하면 구하고, 도둑도 잡아야 해. 그냥 참여한 것처럼 보이기만 하는 게 아니라 내가 직접 해 볼 수 있어야 해."

위 문장은 설명을 취합한 **의미 재구성**이며 원음성의 문자 그대로 인용은 아니다. **실제(real)**은 현실 세계에서 실물 로봇이 등장한다는 뜻이 아닌, *게임 안에서 조작·이동·판정·보상·상태 변화가 실제로 존재한다*는 뜻으로 해석한다.

## 4. 상호작용 플로우 (최소 5분 플레이)


1. 현준이가 마을로 입장한다. 집·길·가게·친구가 평소처럼 보인다. 손목의 **소환 시계** UI를 연다.
2. **경찰 로봇 그림 카드**를 누른다. 물리 카드 줍기/삽입 없이 로봇이 등장한다. 로봇이 따라오거나 명령에 반응한다.
3. 소방/하늘 로봇도 시계에서 선택 가능하다. **합체 버튼**을 누르고 경찰+소방 로봇을 선택 → 두 파츠가 실제로 결합된 2단 합체체로 바뀐다. 3개 선택 시 독립된 3단 형태가 된다.
4. 악당 로봇이 월드에 나타나 공격한다. 합체 로봇을 움직여 접근해 칼/장비를 전개하고 기술을 쓴다. 맞힌 기술에 따라 적 체력이 감소한다. 승리하면 적은 부서지거나 사망하지 않고 **고장·후퇴·수리**한다.
5. 경찰 로봇의 기술이 실제로 7번 유효하게 쓰이면 **7/7 및 강화 연출**이 나오고 다음 능력이 열린다. 기존 카드는 사라지지 않는다.
6. 위험해진 친구 NPC가 도움을 청한다. 지도/현장 표시를 보고 이동, 로봇 기술로 구조해 안전 상태로 바꾼다. 또는 움직이는 도둑 로봇을 추적해 잡는다.
7. 받은 재료로 강화한다. 새로고침·재접속 후 **자동차/집/별코인/로봇 성장**이 보존된다.

## 5. 비주얼·UX 기준

- 시계는 **로봇을 불러내는 기계적 장치**로 보여야 한다. 회전하는 베젤, 로봇 카드 그림, 카드 선택 반응, 소환 에너지/스캔 연출 등. 7세도 글을 많이 읽지 않고 사용할 수 있게 화면을 설계한다.
- **그림 카드의 로봇 외형과 실제 월드 로봇 외형을 일치**시킨다. 별도의 실물 카드 삽입 UX는 넣지 않는다.
- 경찰 **차가 아니라 경찰 로봇**. 다른 로봇과 실제 합체·출동·범인 잡기 가능.
- 합체는 같은 스프라이트 2개를 겹치는 것이 아니다. 합체 전 서로 독립된 엔티티가 결합 도중 이동·변형되고, 완성 시 한 몸의 머리·몸통·팔·다리·무기에서 각 파츠의 기여가 보이도록 한다.
- 액션 HUD는 오른쪽 버튼 과밀을 방지. 시계/액션/합체 등 중요한 버튼은 상황에 맞게 직접 접근 가능. 아이가 메뉴 속을 여러 단계 헤매지 않도록 한다.
- 수집·세계관은 '메탈 카드봇/또봇/헬로 카봇' 장르의 **기계 합체의 재미만 참고**, 기존 캐릭터의 디자인/상표/음향/대사를 복제하지 않는다.
- 위험 인물/악당은 가상의 로봇 제국. 실제 국가/민족과 연결하지 않는다.

## 6. 안전과 데이터 계약

1. 잔인한 폭력, 사람 부상, 도박형 유료 강화·뽑기·현금결제 없음.
2. 임무 실패·합체 해제 시 기존 로봇 카드·차량·재료·진행도를 잃지 않음.
3. 가족방 Supabase Auth/Realtime 기능을 건드리지 않음. 로봇 보상 상태를 Realtime 메시지에 무분별하게 추가하지 않음.
4. `.env`/비밀키를 코드, 로그, 문서, PR에 출력하지 않음. 아동 개인정보 신규 수집 금지.
5. Lovable 연결 저장소이므로 기발행 커밋을 강제 수정·재작성하지 않음.
