**핵심 판정:** UI를 보기만 한 증거는 불충분. 아이가 터치해서 **로봇 상태·월드 좌표·전투/구조 상태·저장 값**이 실제로 변해야 PASS.

## 2. 특히 막아야 할 거짓 양성(false PASS)

- `합체` 버튼 누른 뒤 '2단 합체 성공' 문구만 나오는 것 → **FAIL**.
- 두 개의 기존 로봇 SVG를 옆에 나란히 그린 상태를 '합체 완성'으로 표시 → **FAIL**.
- `친구 구조 성공` 텍스트만 바뀌며 실제 친구 NPC/상태가 없음 → **FAIL**.
- 악당이 플레이어 바로 옆 고정 오버레이이고 타격/거리 계산 없음 → **FAIL**.
- 7/7 카드가 채워지고 기존 로봇의 외형·능력은 그대로 → **FAIL**.
- 단위 테스트만 통과했는데 스마트폰·브라우저 렌더를 확인하지 않음 → **검증 부족**.
- 신규 게임 화면은 동작하지만 집/차량/가족방 저장이 손실 → **FAIL**.

## 3. 자동 검증

현재 저장소 `package.json` 기준 스크립트 존재를 확인한 뒤 실행:

```bash
bun install --frozen-lockfile
npm test
npx tsc --noEmit
npm run lint
npm run build
npm run build:pages
```

별도 헤드리스 브라우저 스크립트는 Playwright-core 및 Chromium 경로 설정이 필요할 수 있음. **해당 환경이 준비되어 있다면** `scripts/verify-robot-world.cjs`를 수정/확장하고 직접 실행한다. `scripts/verify-child-play.cjs`, `scripts/verify-living-world.cjs`, `scripts/verify-building-interiors.cjs`, `scripts/verify-family-performance.cjs`를 회귀 검증에 사용하되 테스트 조건을 사전 확인할 것.

권장 단위 테스트 항목:

1. 카드 미보유/기초 카드/7회 해금 정상화; 0~7 클램프; 여러 탭/쿨다운 중복 계수 방지.
2. 소환 로봇 소유권·월드 좌표·이동·명령 상태 전이; 영역 변경 시 안전한 종료.
3. 동일 robotId의 중복 합체 거부, 2·3단 합체/해제 시 카드 보존.
4. 공격 사거리·장착 무기 상태·데미지·무효 공격·반격/수리·격파 보상 1회.
5. 구출 NPC 상태머신 (위험→도움 요청→진입→구출→안전), 도둑 AI 상태머신 (도주→추적→포획→후퇴).
6. localStorage 저장/복구 `GameState.version:3`, 이전 v3 저장의 자동차·별코인·집·농장 변동 없음.
7. 부모/아이 별 기기 독립 로컬 진행 및 Supabase 가족방 회귀.
8. 키보드가 없는 터치 환경에서 직접 이동 및 버튼을 눌러 액션 일어나고 오류 0건.

## 4. 시각/실기기 QA

- [ ] 데스크톱 `1280×900`: 2단 합체 프레임 전/중/후, 공격 프레임, 구조 전/후 스크린샷
- [ ] 스마트폰 `390×844`: 시계 카드 6개·선택 로봇·확대 버튼, 조이스틱과 오른쪽 버튼 간섭 없음
- [ ] 세로/가로 회전: 오버레이가 화면 밖으로 이탈하지 않음
- [ ] 작은 화면/큰 폰트 설정: 시계 스크롤 가능, 닫기 접근 가능
- [ ] 터치 7회 판정: 중복 탭으로 8/7이 되지 않음
- [ ] 실제 삼성 브라우저: NOT_RUN이면 NOT_RUN 표기
- [ ] 실제 S Pen: NOT_RUN이면 NOT_RUN 표기
- [ ] 현준이 직접 플레이: 보호자 확인 전에는 NOT_RUN

## 5. 완료 보고 형식

최종 보고서에는 반드시 아래를 포함:

```text
1. 구현 결론: PASS / PARTIAL / FAIL (근거를 한 문장으로)
2. 기준 SHA, 작업 브랜치, 변경 커밋 및 PR
3. 요구 ID별 구현 여부(FACT) + 한계(UNKNOWN/NOT_RUN)
4. PR #38/#39에서 무엇을 통합했고 무엇을 버렸는지
5. 실행 테스트: 명령, PASS/FAIL 수치, 실패 로그/해결
6. 브라우저 스크린샷/동작 증거의 경로 및 시나리오
7. 기존 저장/기능 회귀 여부
8. 실기기 및 아이 직접 UAT 상태(검증하지 않았다면 절대 PASS 금지)
9. 남은 P1/P2 작업과 별도 승인 필요한 행동
```

**최우선 실습 검수:** 현준이가 "소환 시계 → 경찰 로봇 부르기 → 소방 로봇과 합체 → 악당에게 무기 쓰기 → 친구 구출 → 7회 업그레이드"를 메뉴만 누르는 것이 아니라 **직접 움직이며** 보여줄 수 있는가.
