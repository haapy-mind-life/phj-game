### 진입 규칙

- **처음 접속** = 이번 앱 실행에서 루트로 처음 들어온 경우. 기억은 메모리에만 있고 저장하지 않는다. 새로고침하거나 새로 열면 시작 화면이 다시 나온다.
- 시작 화면을 지나면, 또는 앱을 `#/race`·`#/kart` 같은 다른 경로로 처음 열었으면, 그 실행에서는 다시 나오지 않는다. 미니게임에서 돌아올 때, 뒤로/앞으로 가기를 할 때도 마찬가지다.
- 경로(URL)는 늘지 않는다. 시작 화면은 루트 경로 안의 상태라 뒤로 가기 의미가 그대로다.
- 두 라우터(TanStack 앱 `src/routes/`, Pages 해시 라우터 `src/pages-entry.tsx`)가 같은 컴포넌트와 훅을 쓴다. 각 루트 컴포넌트가 `useMarkEntryRoute()`로 첫 경로를 기록한다.

### 로딩이 실제로 기다리는 것

1. **월드 화면 코드**: `Village`를 이제 버튼을 누를 때 따로 내려받는다(`import("./Village")`). 첫 화면 JS가 880kB → 626kB로 줄었고, 월드 코드(261kB)는 시작 후에 받는다. 실패할 수 있는 실제 작업이다.
2. **저장 읽기**: 기존 저장소(`useGame().ready`). 저장 읽기 경고(`storageWarning`)는 실패로 보지 않는다(기존과 같다).
3. **최소 표시 600ms**: 화면이 번쩍 지나가지 않게 하는 연출일 뿐이다. 1·2가 끝나야 월드로 넘어가고, 시간만으로는 넘어가지 않는다. 퍼센트 진행률은 없다.
4. **실패**: 코드 받기 실패 또는 12초 초과 시 「길이 잠깐 막혔어요 · 다시 가기」. 브라우저는 실패한 모듈 요청을 그 페이지가 끝날 때까지 기억하므로, 「다시 가기」는 페이지를 새로 열고 시작 버튼 없이 바로 로딩으로 이어 간다. 이때 쓰는 1회용 표시(`sessionStorage` `phj-world-entry-retry`)는 읽자마자 지우며 게임 저장과 관계없다.
5. 스타일은 기존과 같은 순서로 첫 화면 CSS에 그대로 남긴다(빌드 CSS를 기준선과 비교: 새 `.we-*` 규칙 외 차이 0).

### 바꾸지 않은 것

- 월드 엔진·이동·조이스틱·충돌·미니게임·러너·온실·집·`/kart` 목록(40개 유지)·로봇 규칙.
- 저장: 키 `hyunjun-game-v2`, `version: 3`, 필드 추가 없음.
- 제목 글씨는 이미 쓰던 「박현준 게임」 브랜드를 다시 썼다. 새 그림 에셋은 만들지 않았다(기존 현준이·자동차·번개 경찰 로봇 그림 재사용).

## 3. 다음 게임 요구 (REQUEST, 구현 안 함)

### 3.1 경찰 롤러코스터
- 경찰차가 레일과 루프를 달리는 별도 운전 게임. 경찰차 탈것 자체가 아니다.
- 앞을 보는 운전 시야. 장애물에 부딪히면 아웃.
- 코인을 모아 날개와 에너지 능력을 강화한다. 작고 튀어나온 멋진 날개.
- 악당에게 에너지를 쏜다. 전기 에너지로 가속하고 날 수 있다.
- 업그레이드하면 **레일 길이가 아니라 날개 성능**이 좋아진다.

### 3.2 펭귄 얼음 깨기
- 얼음을 깨고 펭귄을 찾아 구한다.
- 구한 펭귄은 보호·전시하거나 자연으로 돌려보내기를 고른다. 나중에 박물관과 연결.
- 「황금 전기」를 얻는 아이디어 → D-2.

### 3.3 개구리 코인별 먹기
- 귀여운 개구리와 현준이가 함께 코인과 별을 모은다.
- 지금 있는 「루루의 별빛 공원」(별 모으기)과 규칙이 달라야 한다. 단조로운 규칙이면 구현 전에 다시 정한다.

### 3.4 박물관·대형 수조
- 박물관: 물고기·거북이·펭귄 전시. 수조: 낚은 물고기를 키우는 곳. 낚시(`호숫가 낚시`)·펭귄 구조와 이어질 후보.

### 3.5 로봇 기지와 이름 제안
- **블루카비**(작업명): 파란 경찰차 변신 로봇, 경찰 로봇 합체, 번개·에너지 능력. 지금 게임의 비슷한 로봇은 「번개 경찰 로봇」(`rb-thunder-police`)이고 시작 화면에서 이 그림을 대신 쓴다.
- **황금 칼드케이트**(작업명): 일반 전설보다 특별한 초황금 전설. 로봇·경찰차·레이싱카·구급차·소방차·비행기·전투기·배·잠수함으로 변신. 황금 전기로 성장. 블루카비·엠블러스와 합체, 연결된 엠블러스도 함께 성장하는 아이디어.
