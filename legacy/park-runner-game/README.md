# Park Runner Game

박현준 러너 어플게임 만들기

Archived snapshot of the earlier park-runner game, kept for history. The live game is the repository root.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
