## 1. 목표

기존 박현준 러너의 점프·스프링·하늘 구름길·비구름·우산·1000점 완주 흐름을 유지하면서, 어린이용 아케이드 스타일의 비그래픽 전투와 성장 아이템을 추가한다.

추가 기능은 다음과 같다.

- 시작 시 방탄조끼, 총, 총알, 활/화살 보유
- 총과 활 2종 무기
- 땅 적과 하늘 적 2종
- 적 처치 보너스 점수
- 방탄조끼로 충돌 1회 방어
- 버섯 획득 시 일시적 거대화
- 키보드와 모바일 터치 조작 모두 지원

## 2. 비목표

이번 범위에는 다음을 포함하지 않는다.

- 사실적인 총기 묘사, 피, 신체 훼손 등 그래픽 폭력 표현
- 상점, 재화, 업그레이드 트리
- 보스전
- 네트워크 멀티플레이
- 계정/서버 저장
- 게임 엔진 전체 재작성

## 3. 기존 동작 보존

아래 기존 기능은 그대로 유지한다.

- `Space` / `ArrowUp` 점프
- 화면 터치 점프
- 스프링 대점프
- 하늘 구름 플랫폼 착지
- 비구름 위험
- 우산 획득 후 비구름 통과
- 자동 진행 점수
- 100점 단위 레벨 상승
- 최고 점수 `localStorage` 저장
- 1000점 도달 시 게임 클리어

## 4. 게임 규칙

### 4.1 초기 장비

게임 시작 시 플레이어 상태:

- 방탄조끼: 1
- 총: 사용 가능
- 총알: 12발
- 활: 사용 가능
- 화살: 6발
- 버섯 거대화: 비활성

재시작 시 위 초기값으로 초기화한다.

### 4.2 무기

#### 총

- 입력: 키보드 `X`
- 모바일: `총` 버튼
- 직선으로 빠르게 전진하는 탄환을 발사한다.
- 발사할 때 총알 1발을 소비한다.
- 총알이 0이면 발사하지 않는다.
- 적 명중 시 해당 적을 제거한다.
- 처치 보너스: `+50점`

#### 활

- 입력: 키보드 `C`
- 모바일: `활` 버튼
- 총알보다 느리고 시각적으로 큰 화살을 발사한다.
- 발사할 때 화살 1발을 소비한다.
- 화살이 0이면 발사하지 않는다.
- 적 명중 시 해당 적을 제거한다.
- 처치 보너스: `+80점`

총과 활 모두 현실적인 탄도/총기 세부 묘사보다 즉시 이해 가능한 아케이드 동작을 우선한다.

### 4.3 적 2종

#### 땅 적

- 지면을 따라 오른쪽에서 왼쪽으로 접근한다.
- 플레이어와 충돌할 수 있다.
- 총/화살로 제거 가능하다.

#### 하늘 적

- 공중 높이에서 오른쪽에서 왼쪽으로 접근한다.
- 점프 또는 하늘 플랫폼 이동 중 플레이어와 충돌할 수 있다.
- 총/화살로 제거 가능하다.

적은 단순 도형/캐릭터형으로 표현하며 잔혹하거나 현실적인 표현을 사용하지 않는다.

### 4.4 플레이어 충돌 우선순위

적과 플레이어가 충돌하면 다음 순서로 처리한다.

1. 거대화 상태이면 적을 제거하고 플레이어는 생존한다.
2. 그렇지 않고 방탄조끼가 1 이상이면 방탄조끼 1개를 소비하고 플레이어는 생존한다.
3. 둘 다 없으면 게임 오버 처리한다.

방탄조끼는 이번 범위에서 추가 획득하지 않고 게임 시작 시 1개만 제공한다.

### 4.5 버섯

- 지면 또는 접근 가능한 낮은 높이에 랜덤 생성한다.
- 플레이어가 획득하면 일정 시간 거대화한다.
- 거대화 배율: 기본 캐릭터의 약 `1.5배`
- 거대화 지속시간: 약 8초 수준의 프레임 기반 타이머
- 거대화 중 적과 충돌하면 적을 제거하고 플레이어는 생존한다.
- 거대화가 끝나면 원래 크기로 돌아온다.

거대화 상태에서는 충돌 박스가 지나치게 커져 난도가 비정상적으로 올라가지 않도록, 시각 크기와 충돌 크기를 분리하거나 제한된 충돌 크기를 사용한다.

## 5. 점수와 레벨

총점은 다음을 합산한다.

- 기존 달리기 점수
- 총 처치: +50
- 화살 처치: +80

기존 `levelOf(score)` 규칙을 유지하므로 처치 보너스도 레벨 상승과 1000점 클리어에 반영한다.

동일 적은 한 번만 점수를 지급한다.

## 6. 입력 설계

### 데스크톱

- `Space` / `ArrowUp`: 점프
- `X`: 총 발사
- `C`: 화살 발사

### 모바일

현재 캔버스 전체 터치를 점프로 사용하는 동작은 유지하되, 캔버스 아래에 별도의 3버튼 컨트롤을 둔다.

- `점프`
- `총`
- `활`

무기 버튼 이벤트는 캔버스의 점프 이벤트로 전파되지 않도록 차단한다.

## 7. HUD

기존 점수/단계/최고 점수 UI에 아래 상태를 추가한다.

- `방탄 1` 또는 `방탄 0`
- `총알 12`
- `화살 6`
- 거대화 활성 시 `버섯 파워` 표시

모바일에서도 한눈에 읽히도록 짧은 텍스트와 단순 아이콘 수준으로 표시한다.

## 8. 코드 구조

기존 `src/routes/index.tsx` 한 파일에 모든 전투 규칙을 추가하지 않는다.

최소 구조:

```text
src/
├─ game/
│  ├─ types.ts
│  └─ combat.ts
└─ routes/
   └─ index.tsx
```

### `src/game/types.ts`

게임 전투 관련 데이터 타입을 정의한다.

예:

- `Enemy`
- `Projectile`
- `Mushroom`
- `WeaponKind`
- 필요 시 `PlayerCombatState`

### `src/game/combat.ts`

순수 계산 중심의 전투 규칙을 둔다.

예:

- 발사 가능 여부
- 발사체 생성
- 발사체/적 충돌 판정
- 처치 점수 계산
- 적/플레이어 충돌 결과 계산

가능한 한 Canvas/React API에 의존하지 않아 단위 테스트가 가능하도록 한다.

### `src/routes/index.tsx`

다음을 담당한다.

- 기존 러너 게임 루프
- 전투 상태와 기존 상태 연결
- 키보드/모바일 입력
- Canvas 렌더링
- HUD
- 게임 시작/종료/재시작

## 9. 상태 모델

기존 `game.current`에 최소한 다음 상태를 추가한다.

- `enemies`
- `projectiles`
- `mushrooms`
- `armor`
- `bullets`
- `arrows`
- `giantTimer`

React state는 화면 표시가 필요한 값만 둔다.

- armor
- bullets
- arrows
- giant active 여부

게임 루프 고빈도 상태는 `useRef`를 우선 사용하여 프레임마다 React 렌더가 과도하게 발생하지 않게 한다.

## 10. 생성 규칙

초기 구현은 과도한 난이도 튜닝을 피한다.

- 적은 화면 오른쪽 바깥에서 생성
- 같은 종류의 적이 너무 가까이 연속 생성되지 않도록 최소 간격 적용
- 하늘 적은 플레이어가 점프하지 않아도 항상 피할 수 없는 배치가 되지 않도록 높이를 제한
- 버섯은 희소하게 등장
- 기존 스프링/플랫폼/비구름/우산 생성과 겹쳐 불가능한 패턴을 만들지 않도록 확률을 보수적으로 설정

## 11. 렌더링 원칙

새 그래픽 자산 의존성을 늘리지 않고 초기에는 Canvas 도형으로 그린다.

- 총: 플레이어 앞의 단순 장난감형 장비 표시 또는 발사 효과
- 총알: 작은 빛나는 점/캡슐
- 화살: 선 + 삼각형 머리
- 방탄: HUD 및 필요 시 플레이어 주변 짧은 보호 효과
- 땅 적/하늘 적: 명확히 구별되는 단순 캐릭터/도형
- 버섯: 밝은 색의 버섯 아이콘형 도형

추후 별도 이미지 자산으로 교체 가능하도록 게임 규칙과 그리기를 분리한다.

## 12. 오류/경계 처리

- 탄약 0에서 발사 입력: 아무 동작도 하지 않음
- 화면 밖 발사체/적/버섯: 즉시 배열에서 제거
- 동일 프레임에 여러 발사체가 같은 적과 충돌: 적 1회 제거, 점수 1회 지급
- 게임 종료/클리어 상태에서 무기 입력: 발사하지 않음
- 재시작 시 이전 적/발사체/버섯/타이머 완전 초기화
- 거대화 중 게임 종료 후 재시작 시 원래 크기로 시작

## 13. 테스트 전략

현재 저장소에 테스트 스크립트가 없으므로 전투 규칙을 순수 함수로 분리한 뒤 최소 테스트 기반을 추가한다.

우선 검증 대상:

1. 총알이 있을 때 총 발사가 총알을 1 감소시키는지
2. 총알 0에서 발사체가 생성되지 않는지
3. 화살 발사 시 화살 1 감소
4. 총으로 적 제거 시 +50점
5. 화살로 적 제거 시 +80점
6. 한 적이 중복 점수를 주지 않는지
7. 거대화 충돌이 적 제거/생존으로 처리되는지
8. 방탄 충돌이 방탄 1 감소/생존으로 처리되는지
9. 보호 수단이 없으면 게임 오버 결과인지
10. 버섯 획득 시 giant timer가 활성화되는지

구현 후에는 최소한 다음을 확인한다.

- 테스트 통과
- `npm run lint`
- `npm run build`
- 기존 게임 시작/점프/우산/스프링/클리어 회귀 여부
